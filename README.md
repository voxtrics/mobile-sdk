# Voxtrics mobile SDK

[![CI](https://github.com/voxtrics/mobile-sdk/actions/workflows/ci.yml/badge.svg)](https://github.com/voxtrics/mobile-sdk/actions/workflows/ci.yml)

Show Voxtrics surveys in Android and iOS apps. Open source under the [MIT license](LICENSE).

- [`android/`](android/README.md) — Kotlin library and demo app (0.1, works against the local stack).
- [`ios/`](ios/README.md) — Swift package (`Package.swift` at the root) and demo app (0.1, works against the
  local stack on the iOS simulator and on a real iPhone).
